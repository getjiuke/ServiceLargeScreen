# 天津市巡查管理平台

基于Vue 3和Element Plus构建的市政道路巡查管理平台，现已重构为本地数据演示版本。

## 项目特性

- 📊 实时数据可视化大屏
- 🗺️ 地图案件分布展示
- 🔐 安全登录验证系统
- 📱 响应式设计
- ⚡ 本地数据快速演示

## 功能模块

### 数据统计面板
- 覆盖面积、单元网格、案件数、巡查人员统计
- 案件分类统计（市容环境、宣传广告、施工管理等）
- 来源占比分析
- 区域结案统计
- 结案趋势展示

### 地图可视化
- 案件点位分布
- 点聚合展示
- 详情信息弹窗

### 数据趋势分析
- 结案趋势图表
- 支持7-31天灵活查询
- 日期范围筛选
- 平滑的图表过渡动画

## 本地运行

### 环境要求
- Node.js 14+
- npm 或 yarn

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

### 构建生产版本
```bash
npm run build
```

## 技术栈

- Vue 3
- Element Plus
- ECharts
- 高德地图API
- Axios
- Vite

## 项目架构

```
src/
├── api/                 # API接口封装
│   ├── login/          # 登录相关接口
│   └── main/           # 主要业务接口
├── components/         # Vue组件
│   └── Main/           # 主界面组件
├── mock/               # 本地Mock数据
│   ├── api.js          # Mock API接口
│   └── data.js         # Mock数据定义
├── utils/              # 工具函数
├── views/              # 页面视图
└── assets/             # 静态资源
```

## 重构说明

本项目已将所有后端接口请求替换为本地Mock数据，主要变更包括：

1. **数据本地化**：所有API调用均返回本地预设数据
2. **登录优化**：验证码功能增强，输入框样式美化
3. **数据丰富**：生成大量演示数据，确保界面充实
4. **功能保留**：保持所有原有功能和数据结构
