# 巡查管理平台

基于Vue 3和Element Plus构建的道路巡查管理平台，现已重构为本地数据演示版本。

## 本地运行

### 环境要求
- Node.js 20
- npm 或 yarn

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

### 构建生产版本
```bash
npm run build
```

## 技术栈

- Vue 3
- Element Plus
- ECharts
- 高德地图API
- Axios
- Vite
